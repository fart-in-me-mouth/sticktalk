Twemoji 17.0.3 PNG artwork, copyright Twitter and other contributors. CC BY 4.0. https://github.com/jdecked/twemoji/tree/v17.0.3
Packed unmodified 72x72 PNGs in lexical codepoint order; twemoji-index.rs gives byte offsets. Unicode 18 provisional entries without artwork display their readable shortcode, never missing-glyph boxes.

The composer uses the same Twemoji artwork in `../fonts/ComposerEmoji.ttf`
(sbix color bitmaps), generated by `../../scripts/build_composer_emoji.py`
with fontTools. Graphics retain the CC BY 4.0 attribution above. The blank
`CustomEmojiAdvance.ttf` face and font assembly are original MIT-licensed code.
At 15px body text the native face reserves a 22px advance and a 24px line box;
custom server artwork uses the same advance and baseline via a bounded overlay.
No operating-system font files are copied or redistributed.
