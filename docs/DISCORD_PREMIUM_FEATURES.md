# Discord premium features

**Verified November 22, 2026.** “Basic” means Nitro Basic. “Nitro” means the full individual subscription. Personal subscriptions follow the account across servers. Server Boosts unlock benefits for everyone in one community, including free members. Discord also sells products for individual servers, apps and games. Their creators set the contents, so those entries describe what each purchase can unlock. ## Server Boosts

Members pool recurring Boosts in a server they choose. Full Nitro supplies two Boosts and discounts additional Boost purchases by 30%. Grandfathered Nitro Classic gets the discount. Nitro Basic supplies neither benefit. A contributor receives the server’s Booster role and an evolving profile badge. Moving a Boost to another server has a seven-day cooldown. [Boosting FAQ](https://support.discord.com/hc/en-us/articles/360028038352-Server-Boosting-FAQ) · [Profile badges](https://support.discord.com/hc/en-us/articles/44369363856663-Discord-Profile-Badges-What-Each-Badge-Means)
