# Free Discord features missing or incomplete in StickTalk

**Reviewed November 22, 2026** against StickTalk commit `fabf21c`, the active Leptos web app, its Windows shell and the Rust server. The comparison covers ordinary free Discord accounts and unboosted servers. Some community, discovery, safety and console features require an eligible server, account, region or device.

Across **51 feature groups**, **32 are missing** and **19 are partial** in this checkout. The most consequential everyday gaps are direct and group calling, searching past messages from the app, conversations in threads and chat inside voice channels. For server owners, the clearest gaps are member timeouts, AutoMod and a moderation audit log.

**How to read the findings.** *Missing* means I found no implementation of the described workflow in the production paths. *Partial* means some of it exists, the server provides it without a usable web control, or a documented limit is lower. Counts refer to the rows below. They group related actions and do not assign a severity or a percentage of overall Discord parity.
